# Devil Painter Asset Library

Free **CC0** texture and material packs made for [DEVIL-PAINTER](https://github.com/Artbyo3/DEVIL-PAINTER). Anyone can use them for free in any program.

## Catalog

Browse and download packs on the [Asset Library Catalog](https://artbyo3.github.io/DEVIL-PAINTER_Asset_Library/).

Every pack carries short tags. On the catalog page, you can click a tag or use the search box to filter the list.

## How Packs Are Organized

- Packs download as ordinary zip files from [this repository's releases](https://github.com/Artbyo3/DEVIL-PAINTER_Asset_Library/releases). The catalog page lists them from [`packs.json`](packs.json) (`name`, `description`, `size`, `downloadUrl`, `tags`).
- Each zip file holds normal image and material files in simple folders. File names use standard texture words (like color, roughness, and normal) so DEVIL-PAINTER can sort them into **Textures** and **Materials** on its own. You can also open the same files directly in Blender or any other 2D or 3D program.

## How to Download

1. Open the [Asset Library Catalog](https://artbyo3.github.io/DEVIL-PAINTER_Asset_Library/) or [the releases page](https://github.com/Artbyo3/DEVIL-PAINTER_Asset_Library/releases).
2. Download the zip file for the pack you want.
3. Unzip it into a folder on your computer. In DEVIL-PAINTER, point your Shelf texture folder to that folder. In any other program, open the unzipped files directly.
