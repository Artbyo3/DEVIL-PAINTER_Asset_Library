# Devil Painter Asset Library

Free **CC0** texture and material packs for the [DEVIL-PAINTER](https://github.com/Artbyo3/DEVIL-PAINTER) Blender add-on, usable by anyone in any tool, with no add-on required.

## Catalog

Browse available packs on the [Asset Library Catalog](https://artbyo3.github.io/DEVIL-PAINTER_Asset_Library/).

## How Packs Are Organized

- Pack archives are hosted as [GitHub Releases](https://github.com/Artbyo3/DEVIL-PAINTER_Asset_Library/releases) on this repository and indexed in [`packs.json`](packs.json) (`name`, `description`, `size`, `downloadUrl`).
- Inside each archive, textures and materials are organized in standard folders using common PBR naming conventions so DEVIL-PAINTER's **Shelf** can scan them automatically into **Textures** and **Materials**, while remaining plain image/asset files ready for Blender or any other 3D or 2D application.

## How to Download

1. Visit the [Asset Library Catalog](https://artbyo3.github.io/DEVIL-PAINTER_Asset_Library/) or open [GitHub Releases](https://github.com/Artbyo3/DEVIL-PAINTER_Asset_Library/releases).
2. Download the archive for the pack you want.
3. Extract it to a folder on disk. In DEVIL-PAINTER, point your Shelf texture folder to the extracted directory (or import individual maps); in any other tool, load the extracted files directly.
